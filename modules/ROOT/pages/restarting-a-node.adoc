== Before You Begin

* Set up and test the backup procedure on all clusters.
* Perform a backup before attempting node maintenance to preserve data in the event of a failure.

== Update Nodes for Clusters

See the following topics for details on each provider:

* https://support.scc.suse.com/s/redirect?language=en_US&id=000021301[Rancher Kubernetes Engine (RKE2) OS Upgrade Process]

* OpenShift: Starting with version 4.16, the Machine Config Operator manages the node's OS updates as part of the cluster update process. For more on node updates and the Machine Config Operator, see:

** https://docs.openshift.com/en/container-platform/4.16/updating/understanding_updates/intro-to-updates.html[Openshift Updates] 

** https://docs.openshift.com/en/container-platform/4.16/updating/understanding_updates/intro-to-updates.html#update-service-about_understanding-openshift-updates[Openshift Update Service]
